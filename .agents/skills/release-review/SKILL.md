# Release review

Inspect the implementation independently from the docs; the docs are claims, the code and reports are evidence.

## Checklist
1. **Scope**: exactly five requirement fields (participants, departure station, departure, return, subject/theme); no budget/destination/age/booking logic crept in; no train or itinerary facts generated by a model.
2. **Invariants** (`AGENTS.md` §3): walk each one against the code. Pay particular attention to: no confirmation without explicit user action; corrections never added to old values; an ambiguous value never stored; evidence check on every model operation; state untouched on provider failure.
3. **Negative paths have tests**: stale `expected_version`, duplicate and conflicting `client_message_id`, provider failure/timeout, invalid/oversized audio, return before departure, edit after confirmation.
4. **Run it**: `./scripts/check.sh`; then `./scripts/demo.sh` and click through the pitch script in `docs/DEMO.md`; then `./scripts/dev.sh` with the real model for the same script. Look at the screens — do not accept a green report without checking which integration it exercised.
5. **Evals**: latest run recorded in `docs/HANDOFF.md` with model, date, pass rate and blocking counts. A mock-mode pass is not model accuracy.
6. **Secrets and data**: `python scripts/secret_scan.py`; `.env`, `.local/`, `artifacts/`, audio and databases are untracked; no `NEXT_PUBLIC_*` secret; INFO logs contain no message text or transcripts.
7. **Parity**: `python scripts/sync_skills.py --check`; `cd services/api && uv run python ../../scripts/export_schemas.py --check`; mock service output validates against the response schema.
8. **Truthfulness**: `docs/HANDOFF.md` lists what was NOT verified (physical devices, screen readers, Postgres path, hosted CI, real planner integration). Demo mode is visibly labelled.
9. **Production gate**: `docs/PRODUCTION.md` items are still open unless really done; nobody removed a guard to make something pass.

## Output
Prioritised findings with `file:line`, a reproducing input and the consequence; or an explicitly bounded "no findings in X, Y, Z". Never a blanket certification. Update HANDOFF and the task board; run `python scripts/handoff.py`.
