# IA Impact — réseau ferré d'Occitanie

- [`backend/`](backend/README.md) — API FastAPI : plus court chemin en temps (Dijkstra) entre deux villes ou gares d'Occitanie (TER train et car, Intercités, TGV), avec filtre par type de transport.
- [`frontend/`](frontend/README.md) — React : carte des gares, liste des lieux et calcul d'itinéraire.
